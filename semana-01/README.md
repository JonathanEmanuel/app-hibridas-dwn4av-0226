# GIT
1.Inicializamos el repositorio
``` bash
    git init
```
2.Configurar el usuario
``` bash
    git config user.name "jonathan Cruz"
    git config user.email hola@jonathancruz.com.ar"
```
3.Agregamos los archivos
``` bash
    git add .
```
4.Creamos el commit -m
``` bash
    git commit -m "Mensaje"
```

5.Realizamos el push
``` bash
    git origin main
```
